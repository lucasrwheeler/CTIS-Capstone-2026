# Project Overview

## Problem Statement
Students and advisors need a clear, reliable way to check course eligibility, plan future semesters, and understand degree progress without manually tracing prerequisites and requirements.

## Intended Users / Stakeholders
- Students planning their courses
- Academic advisors
- Faculty evaluators reviewing the capstone
- Future developers extending the system

## Project Goals
- Provide an eligibility engine for courses based on prerequisites
- Offer explanations for why a student is or is not eligible
- Support long-term planning (e.g., “what can I take next?” and degree progress)
- Deploy the system using realistic, cloud-native architecture (React frontend, AWS backend, IaC)
