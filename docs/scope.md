# System Scope

## In Scope
- Backend eligibility and prerequisite engine
- Explanation engine for course eligibility
- Cloud-native backend using AWS (Lambda, API Gateway, RDS, VPC, IAM)
- React-based frontend for students and advisors
- Infrastructure as Code using Terraform

## Out of Scope
- Integration with a real university SIS
- Mobile applications
- Real student data in production
- Full production-grade authentication/authorization
